Guide: how to obtain an AI API key Hide
Supported plans: Google Gemini API key (free tier), Groq (gsk_...), OpenRouter (sk-or-...), OpenAI, or Anthropic.
1 Open the provider portal Google AI Studio and sign in with your account.
2 Click "Create API key" and copy your key (starts with AIzaSy...).
3 Paste the key below and click "Verify & save". The key stays strictly inside your local Firefox profile.
Guide: running local Open AI with Ollama ($0 API cost)
Note: Anyone installing this extension must install Ollama separately on their computer (browsers cannot bundle desktop AI engines).
1 Install Ollama and pull a lightweight model: ollama pull qwen2.5:3b (and optionally ollama pull qwen2.5vl:3b for image OCR).
2 Keep Ollama running locally and click "Verify & connect" below. If Firefox blocks CORS (HTTP 403), set OLLAMA_ORIGINS=* and restart Ollama.
